# Security policy

Please do not open a public issue for a vulnerability, exposed credential, or a
report containing private audio or transcript data. Use GitHub's private
vulnerability reporting feature for this repository instead.

Include the affected version, macOS version, impact, reproduction steps, and a
minimal redacted example. Do not include Gemini API keys, full `settings.json`,
private recordings, or unredacted `result.json` files.

Only the latest public preview release is supported with security fixes.
